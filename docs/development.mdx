GitArena consists of a Rust backend and a Next.js frontend. Run both during frontend or full-stack development.

## Prerequisites

| Tool | Version | Purpose |
|------|---------|---------|
| Rust | stable (latest) | Backend compilation |
| Node.js | 18+ | Frontend |
| pnpm | latest | Frontend package manager |
| PostgreSQL | 14+ | Database |

Install the Rust toolchain via [rustup](https://rustup.rs):

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

Install pnpm:

```bash
npm install -g pnpm
```

## Local setup

<Steps>
  <Step title="Clone the repository">
    ```bash
    git clone https://github.com/mellowagain/gitarena.git
    cd gitarena
    ```
  </Step>
  <Step title="Set up the database">
    Create a development database and set the backend environment:

    ```bash
    createdb gitarena_dev
    ```

    ```bash .env
    DATABASE_URL=postgres://your_user@localhost/gitarena_dev
    BIND_ADDRESS=127.0.0.1:8080
    ```

    Migrations run automatically when GitArena starts. Do not run `sqlx migrate run` manually.
  </Step>
  <Step title="Run the backend">
    ```bash
    cargo build
    cargo run -p gitarena
    ```

    The backend starts at `http://127.0.0.1:8080` and logs to the console in debug mode. Background jobs run in-process; there is no separate background service to start.
  </Step>
  <Step title="Run the frontend">
    ```bash
    cd gitarena-frontend
    pnpm install
    pnpm run dev
    ```

    The Next.js dev server starts at `http://localhost:8321`. By default it proxies `/api/*` and smart HTTP `*.git` paths to `http://localhost:8080`. Override the backend target with `NEXT_PUBLIC_API_URL`.
  </Step>
</Steps>

For faster backend iteration, use `cargo check` to type-check without producing a binary:

```bash
cargo check
```

## Available commands

### Backend (Rust)

| Command | Description |
|---------|-------------|
| `cargo build` | Debug build |
| `cargo build --release` | Release build with LTO |
| `cargo build -p gitarena` | Build a single crate |
| `cargo test` | Run all tests |
| `cargo test -p gitarena` | Test a single crate |
| `cargo clippy` | Lint |
| `cargo fmt` | Format (max width 160, set in `rustfmt.toml`) |
| `cargo fmt -- --check` | Check formatting without changes |

### Frontend (TypeScript)

| Command | Description |
|---------|-------------|
| `pnpm run dev` | Start dev server |
| `pnpm run build` | Production build |
| `pnpm run lint` | Run ESLint |
| `pnpm run format` | Run Prettier |
| `pnpm run format:check` | Check formatting |

<Warning>
  Always use `pnpm run lint`, not `pnpm lint`. The `run` keyword is required.
</Warning>

## Logs

GitArena writes logs to stdout unless `NO_STDOUT_LOG` is set. File logging is disabled unless `DEBUG_FILE_LOG` is set, and file logging is not enabled in debug builds.

## Project layout

| Path | Purpose |
|------|---------|
| `gitarena/` | Main Actix-Web backend binary |
| `gitarena-macros/` | Proc-macro crate |
| `gitarena-frontend/` | Next.js frontend |
| `migrations/` | SQL migrations that run automatically on startup |
