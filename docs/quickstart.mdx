---
title: "Quickstart"
description: "Start the current Docker backend and connect it to Postgres."
---

<Warning>
  Docker support currently builds the Rust backend only. The image does not build or serve the Next.js frontend, so a full web instance needs the frontend deployed separately.
</Warning>

## Prerequisites

- Docker and Docker Compose installed
- A checked-out GitArena repository if you build the local Dockerfile
- A separate frontend deployment or development server for the user-facing UI

<Steps>
  <Step title="Create a Compose file">
    Use this Compose file from the repository root:

    ```yaml docker-compose.yml
    services:
      postgres:
        image: postgres:trixie
        environment:
          POSTGRES_DB: gitarena
          POSTGRES_USER: gitarena
          POSTGRES_PASSWORD: change_me
        volumes:
          - pgdata:/var/lib/postgresql/data
        healthcheck:
          test: ["CMD-SHELL", "pg_isready -U gitarena"]
          interval: 5s
          timeout: 5s
          retries: 5

      gitarena:
        build: .
        depends_on:
          postgres:
            condition: service_healthy
        environment:
          BIND_ADDRESS: "0.0.0.0:8080"
          DATABASE_URL: "postgres://gitarena:change_me@postgres/gitarena"
        volumes:
          - repos:/repositories
        ports:
          - "127.0.0.1:8080:8080"
          - "2222:2222"

    volumes:
      pgdata:
      repos:
    ```

    Replace both `change_me` values with the same strong password.

    <Warning>
      Don't expose port 8080 directly to the internet. Bind it to `127.0.0.1` and put a reverse proxy in front of it. See the [reverse proxy guide](/self-hosting/reverse-proxy).
    </Warning>
  </Step>

  <Step title="Start GitArena">
    ```bash
    docker compose up -d
    ```

    Docker builds the backend image, starts Postgres, waits for the health check to pass, then starts GitArena. Migrations run automatically on first start.

    ```bash
    docker compose ps
    ```

    The backend is reachable at `http://127.0.0.1:8080` once both services show `running`.
  </Step>

  <Step title="Set the repository path">
    Configure the repository storage path to match the mounted volume:

    ```bash
    docker compose exec postgres psql -U gitarena -d gitarena -c \
      "UPDATE settings SET value = '/repositories' WHERE key = 'repositories.base_dir';"
    ```
  </Step>

  <Step title="Create your admin account">
    Register your first account through the frontend connected to this backend.

    Then grant yourself admin access:

    ```bash
    docker compose exec postgres psql -U gitarena -d gitarena -c \
      "UPDATE users SET admin = true WHERE username = 'your_username';"
    ```

    Your next request has access to the admin panel at `/admin`.
  </Step>
</Steps>
