## Prerequisites

- Docker and Docker Compose installed
- A checkout of the GitArena repository

<Steps>
  <Step title="Start GitArena">
    From the repository root:

    ```bash
    POSTGRES_PASSWORD=change_me docker compose up -d
    ```

    Replace `change_me` with a strong password. Docker pulls the backend and frontend images, starts PostgreSQL, runs the migrations, configures the instance for `http://localhost`, then starts the backend, frontend and Caddy.

    ```bash
    docker compose ps
    ```

    GitArena is reachable at `http://localhost` once `gitarena`, `frontend` and `caddy` show `running`.

    <Tip>
      To serve a real domain over HTTPS, or to add search, object storage and observability, see the [Docker guide](/self-hosting/docker).
    </Tip>
  </Step>

  <Step title="Create your admin account">
    Register your first account at `http://localhost/register`.

    Then grant yourself admin access:

    ```bash
    docker compose exec postgres psql -U gitarena -d gitarena -c \
      "UPDATE users SET admin = true WHERE username = 'your_username';"
    ```

    Your next request has access to the admin panel at `/admin`.
  </Step>
</Steps>
