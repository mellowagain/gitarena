---
title: "Reverse proxy"
description: "Put Nginx or Caddy in front of GitArena for TLS termination and static file serving."
---

GitArena should run behind a reverse proxy in production for TLS termination and real IP forwarding.

Once HTTPS is in place, enable it in your instance settings so GitArena adds the `Secure` flag to session cookies:

```sql
UPDATE settings SET value = 'true' WHERE key = 'https';
```

## Nginx

```nginx /etc/nginx/sites-available/gitarena
server {
    listen 80;
    server_name git.example.com;

    # Redirect HTTP to HTTPS
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl http2;
    server_name git.example.com;

    ssl_certificate     /etc/letsencrypt/live/git.example.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/git.example.com/privkey.pem;

    # Git operations can involve large pack files
    client_max_body_size 500m;

    location / {
        proxy_pass         http://127.0.0.1:8080;
        proxy_set_header   Host              $host;
        proxy_set_header   X-Real-IP         $remote_addr;
        proxy_set_header   X-Forwarded-For   $proxy_add_x_forwarded_for;
        proxy_set_header   X-Forwarded-Proto $scheme;

        # Required for git push/pull and log streaming (SSE)
        proxy_buffering    off;
        proxy_read_timeout 300s;
    }
}
```

Enable the site and reload Nginx:

```bash
sudo ln -s /etc/nginx/sites-available/gitarena /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

## Caddy

Caddy handles TLS automatically via Let's Encrypt.

```caddy /etc/caddy/Caddyfile
git.example.com {
    reverse_proxy 127.0.0.1:8080 {
        # Required for git push/pull and log streaming (SSE)
        flush_interval -1
    }

    # Increase timeouts for large git operations
    request_body {
        max_size 500MB
    }
}
```

Reload Caddy:

```bash
sudo systemctl reload caddy
```

## Notes

- **`proxy_buffering off`** (Nginx) / **`flush_interval -1`** (Caddy) — required for Server-Sent Events (the live log stream in the admin panel) and for large git pack file transfers.
- **`client_max_body_size`** — set this large enough to accommodate git push operations with large files. 500 MB is a reasonable default; adjust based on your repository sizes.
- **X-Forwarded-For** — GitArena uses this header to record the real client IP in sessions. Make sure your proxy sets it correctly.
- **Large file support** — If you use Git LFS, increase the body size limit to match your largest expected LFS object.
