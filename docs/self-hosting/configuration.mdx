---
title: "Configuration"
description: "Environment variables and instance settings for GitArena."
---

GitArena is configured through environment variables read at startup and instance settings stored in the `settings` table in PostgreSQL.

<Note>
  The current admin panel does not provide a complete settings editor. Edit settings directly in PostgreSQL for now.
</Note>

## Environment variables

Set these before starting GitArena. In Docker, pass them under `environment:` in your Compose file.

### Required

| Variable | Description |
|----------|-------------|
| `BIND_ADDRESS` | Socket address to listen on, e.g. `0.0.0.0:8080` or `127.0.0.1:8080`. The port is required. |
| `DATABASE_URL` | PostgreSQL connection string, e.g. `postgres://user:pass@host/dbname`. Required by the background queue at startup. |

### Credentials as files

| Variable | Description |
|----------|-------------|
| `DATABASE_URL_FILE` | Path to a file containing the full `DATABASE_URL`. Supported by the main database pool, but not by queue startup. |
| `DATABASE_PASSWORD_FILE` | Path to a file containing only the database password. Supported by the main database pool, but not by queue startup. |

### Optional

| Variable | Description |
|----------|-------------|
| `MAX_POOL_CONNECTIONS` | Maximum number of Postgres connections to keep open. |
| `NO_STDOUT_LOG` | Disable stdout logging when set. |
| `DEBUG_FILE_LOG` | Enable rolling file logging in non-debug builds when set. |

## Instance settings

Instance settings live in the `settings` table. Edit them directly with SQL:

```sql
-- Read a setting
SELECT value FROM settings WHERE key = 'domain';

-- Update a setting
UPDATE settings SET value = 'https://git.example.com' WHERE key = 'domain';
```

Some settings are read at startup, while others are read per request. Restart GitArena after direct database edits if the behavior does not update immediately.

### Instance

| Key | Default | Description |
|-----|---------|-------------|
| `domain` | `http://localhost:8080` | Public base URL of the instance. Session cookies use `Secure` when this starts with `https`. |
| `secret` | Generated | Secret used for cookie key material. |
| `allow_registrations` | `true` | Allow new users to register. Set to `false` to close registrations. |

### Repositories

| Key | Default | Description |
|-----|---------|-------------|
| `repositories.base_dir` | `null` | Filesystem directory where bare repositories are stored. Set this before creating repositories. |
| `repositories.importing_enabled` | `true` | Enable repository imports through `POST /api/repo/import`. |

### WebAuthn (passkeys)

| Key | Description |
|-----|-------------|
| `webauthn.origin` | The origin for WebAuthn operations, e.g. `https://git.example.com`. Must match the URL users access GitArena at. |

### SMTP (email)

| Key | Description |
|-----|-------------|
| `smtp.enabled` | Enable email delivery |
| `smtp.server` | SMTP server hostname |
| `smtp.port` | SMTP server port |
| `smtp.tls` | Use implicit TLS |
| `smtp.address` | From address for outgoing emails, e.g. `noreply@example.com` |
| `smtp.username` | SMTP login username |
| `smtp.password` | SMTP login password |

### hCaptcha

| Key | Description |
|-----|-------------|
| `hcaptcha.enabled` | Enable hCaptcha-related registration checks |
| `hcaptcha.site_key` | hCaptcha site key. Registration requires an `h-captcha-response` when this is set. |
| `hcaptcha.secret` | hCaptcha secret key setting. Current verification behavior is still being aligned with this key. |

### SSO

| Key | Description |
|-----|-------------|
| `sso.github.enabled` | Enable GitHub OAuth2 sign-in |
| `sso.github.client_id` | GitHub OAuth app client ID |
| `sso.github.client_secret` | GitHub OAuth app client secret |
| `sso.gitlab.enabled` | Enable GitLab OAuth2 sign-in |
| `sso.gitlab.app_id` | GitLab OAuth app application ID |
| `sso.gitlab.client_secret` | GitLab OAuth app client secret |
| `sso.bitbucket.enabled` | Enable Bitbucket OAuth2 sign-in |
| `sso.bitbucket.key` | Bitbucket OAuth consumer key |
| `sso.bitbucket.secret` | Bitbucket OAuth consumer secret |

### SSH

| Key | Default | Description |
|-----|---------|-------------|
| `ssh.enabled` | `true` | Enable the built-in SSH server |
| `ssh.port` | `2222` | Port the SSH server binds to |
| `ssh.private_key` | Generated | Host private key generated on first startup |

### GeoIP

GeoIP lookups use an embedded MaxMind database. There are no runtime settings for GeoIP paths or enablement.
