GitArena is a self-hosted git platform built with a Rust backend and a Next.js frontend. It provides repository hosting over smart HTTP and SSH, user accounts, passkeys, SSO, and an admin panel.

## What GitArena includes

<Columns cols={2}>
  <Card title="Git hosting" icon="code-branch">
    Push and pull over smart HTTP and SSH. Create and import repositories. Language and license detection run after each push.
  </Card>
  <Card title="Issue tracking" icon="circle-dot">
    Browse the current issue pages while the full issue workflow is under active development.
  </Card>
  <Card title="Merge requests" icon="code-merge">
    View the current merge request pages while creation, review, and merge flows are being built.
  </Card>
  <Card title="User accounts" icon="user">
    Cookie-based sessions, passkey (WebAuthn) authentication, SSH key management, and per-session device tracking with revocation.
  </Card>
  <Card title="SSO" icon="key">
    Sign in with GitHub, GitLab, or Bitbucket. Each provider is individually enabled in the settings table.
  </Card>
  <Card title="Admin panel" icon="shield">
    View instance stats, health checks, and user accounts. Grant admin access directly in the database.
  </Card>
</Columns>

## How it's built

GitArena is split into a backend, frontend, and proc-macro crate.

| Component | Role |
|-----------|------|
| `gitarena` | Actix-Web backend, smart HTTP, built-in SSH, migrations, queue workers |
| `gitarena-frontend` | Next.js frontend |
| `gitarena-macros` | Proc-macro crate for config and route helpers |
