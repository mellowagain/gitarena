title: "Issues and merge requests"
description: "Current status of issue and merge request pages in GitArena."
---

GitArena currently includes repository pages for issues and merge requests, but the full workflows are still under active development.

<Note>
  The current frontend pages use placeholder data. Issue creation, issue updates, merge request creation, diffs, discussions, approvals, and merging are not complete user-facing features yet.
</Note>

## Issues

Issue tables exist in the database and some backend code exists, but the issue route is not currently registered as a complete API workflow. The frontend issue list and detail pages are useful for UI development and design review, not production issue tracking.

## Merge requests

Merge request list and detail pages exist in the frontend with placeholder content. Backend merge request creation, review, and merge behavior is not implemented as a complete feature yet.

## API

Use the [GitHub issues](https://github.com/mellowagain/gitarena/issues) tab for current implementation status.
