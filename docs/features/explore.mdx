The Explore page at `/explore` lists all public repositories on the instance. It's accessible without an account.

<Frame>
  <img src="/readme_screenshots/explore.png" alt="GitArena Explore page showing public repositories" />
</Frame>

## What's shown

Each repository card displays the name and owner, description (if set), primary language, star count, and last updated time. Repositories are listed by most recently updated.

## User profiles

Each user has a public profile at `/{username}` showing their public repositories, bio, and account creation date. No authentication required.

## API

The explore endpoint is documented in the [API reference](/api-reference/introduction).
