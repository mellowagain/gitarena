The Explore page at `/explore` lists all public repositories on the instance. It's accessible without an account.

<Frame>
  <img src="/readme_screenshots/explore.png" alt="GitArena Explore page showing public repositories" />
</Frame>

## What's shown

Each repository card displays the owner/name, description, visibility, primary language, star count, and issue count. The default **Popular** view sorts by `stars_desc`; the **New** view sorts by newest repository ID.

## User profiles

Each user has a public profile at `/{username}` showing their public repositories, account stats, and joined date. No authentication is required for public profiles.

## API
