The admin panel at `/admin` is only accessible to users with `admin = true` in the `users` table. The current panel provides instance stats, component health, and user management views.

<Note>
  Settings editing, audit logs, and live log streaming are visible as work-in-progress sections in the frontend, but they are not complete admin features yet.
</Note>

## Granting admin access

Admin access is set directly in the database — there is no web UI for this, which prevents privilege escalation through the application layer.

```bash
# Using Docker
docker compose exec postgres psql -U gitarena -c \
  "UPDATE users SET admin = true WHERE username = 'your_username';"

# Using psql directly
psql -U gitarena -c "UPDATE users SET admin = true WHERE username = 'your_username';"
```

Admin access is checked on each request. You do not need to restart GitArena after updating the database.

## Dashboard

The dashboard shows user count, organization count, repository count, total repository disk space, and used repository disk space.

## Settings

Instance settings are stored in the `settings` table. Edit settings directly in PostgreSQL for now. See the [configuration reference](/self-hosting/configuration) for available keys and their descriptions.

## Live log streaming

The backend contains internal SSE/logging helpers, but no complete admin log stream endpoint is currently exposed.
