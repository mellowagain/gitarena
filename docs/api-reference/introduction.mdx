The GitArena API is the same REST API the web interface uses.

## Base URL

```
https://api.git.mari.zip/api
```

## Authentication

Public data, such as public repositories, profiles and search, can be read without authentication. Everything else returns `401` without valid credentials.

## Requests

Bodies are JSON with `camelCase` field names. Send `Content-Type: application/json` with every request that has a body.

## User agent

Set a `User-Agent` that names your integration:

```
User-Agent: my-integration/1.0 (https://example.com/my-integration)
```

<Warning>
  Instances will soon be able to block generic user agents such as `curl`.
</Warning>

## Pagination

List endpoints take `offset` and `limit` query parameters:

```bash
curl -A "my-integration/1.0 (https://example.com/my-integration)" \
  "https://api.git.mari.zip/api/search/repositories?query=gitarena&offset=20&limit=20"
```

## Errors

Errors return a message:

```json
{
  "error": "Repository not found"
}
```

Private resources you can't access return `404` instead of `403`, so their existence isn't revealed. `500` responses don't include details; they are only logged on the instance.

<Note>
  **Self-hosting?** Replace the base URL with your instance's domain. Every instance also serves its OpenAPI document at `/api-docs/openapi.json` and an API explorer at `/rapidoc`.
</Note>
