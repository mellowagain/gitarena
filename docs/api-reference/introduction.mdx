GitArena exposes a REST API used by the frontend and available for integrations. All endpoints are documented with OpenAPI and viewable in the interactive explorer.

## Base URL

```
https://your-instance.example.com
```

API endpoints are prefixed with `/api/`. For example:

```
GET https://your-instance.example.com/api/repositories/alice/my-repo
```

## Interactive explorer

GitArena includes a [RapiDoc](https://rapidocweb.com) API explorer at `/rapidoc`. You can browse all endpoints, view request/response schemas, and make live requests directly from the browser.

The raw OpenAPI specification is available at:

```
GET /api-docs/openapi.json
```

## Authentication

Most read endpoints for public data (public repositories, explore, user profiles) don't require authentication.

Write operations and private data require an active session. GitArena uses **cookie-based sessions** — there is no API token system. To authenticate:

1. Log in via `POST /api/login` with your credentials.
2. The response sets a `gitarena-auth` session cookie.
3. Include this cookie in subsequent requests.

```bash
# Log in and save the cookie
curl -c cookies.txt -X POST https://your-instance/api/login \
  -H "Content-Type: application/json" \
  -d '{"username": "alice", "password": "secret"}'

# Use the session cookie for authenticated requests
curl -b cookies.txt https://your-instance/api/me
```

## Error format

Errors from GitArena's user-facing endpoints return JSON with an HTTP status code and a message:

```json
{
  "error": "Repository not found"
}
```

Unexpected server errors return `500 Internal Server Error` without a body. The error details are logged server-side.

## Pagination

Endpoints that return lists support pagination via query parameters:

| Parameter | Description |
|-----------|-------------|
| `page` | Page number, 1-indexed |
| `per_page` | Results per page (default varies by endpoint) |

Pagination metadata is included in the response body.

## Key endpoints

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/api` | Instance information |
| `POST` | `/api/login` | Log in |
| `POST` | `/api/logout` | Log out |
| `GET` | `/api/me` | Current user |
| `GET` | `/explore` | List public repositories |
| `POST` | `/api/repositories` | Create a repository |
| `GET` | `/api/repositories/{user}/{repo}` | Repository metadata |
| `POST` | `/api/repositories/{user}/{repo}/fork` | Fork a repository |
| `GET` | `/api/sessions` | List active sessions |
| `DELETE` | `/api/sessions/{hash}` | Revoke a session |
| `GET` | `/api/ssh-keys` | List SSH keys |
| `POST` | `/api/ssh-keys` | Add an SSH key |
| `GET` | `/api/sso` | List enabled SSO providers |
| `GET` | `/healthz` | Health check |

Browse the full list of endpoints in the interactive explorer at `/rapidoc`.
