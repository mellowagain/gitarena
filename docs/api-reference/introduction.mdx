GitArena exposes a REST API used by the frontend and available for integrations. The interactive explorer shows the generated OpenAPI document.

<Note>
  OpenAPI coverage is still being filled in for some older routes. The key route table below reflects the current backend route names.
</Note>

## Base URL

```
https://your-instance.example.com
```

API endpoints are prefixed with `/api/`. For example:

```
GET https://your-instance.example.com/api/repos/alice/my-repo
```

## Interactive explorer

GitArena includes a [RapiDoc](https://rapidocweb.com) API explorer at `/rapidoc`. You can browse the generated OpenAPI endpoints, view request/response schemas, and make live requests directly from the browser.

The raw OpenAPI specification is available at:

```
GET /api-docs/openapi.json
```

## Authentication

Most read endpoints for public data (public repositories, explore, user profiles) don't require authentication.

Write operations and private data require an active session. GitArena uses **cookie-based sessions** — there is no API token system. To authenticate:

<Steps>
  <Step title="Log in">
    Send credentials to `POST /api/auth/login`.
  </Step>
  <Step title="Store the cookie">
    The response sets a `gitarena-auth` session cookie.
  </Step>
  <Step title="Use authenticated endpoints">
    Include the cookie in subsequent requests.
  </Step>
</Steps>

```bash
# Log in and save the cookie
curl -c cookies.txt -X POST https://your-instance/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username": "alice", "password": "secret"}'

# Use the session cookie for authenticated requests
curl -b cookies.txt https://your-instance/api/auth/me
```

## Error format

Errors from GitArena's user-facing endpoints return JSON with an HTTP status code and a message:

```json
{
  "error": "Repository not found"
}
```

Unexpected server errors return a generic `500 Internal Server Error` response, usually as `{"error":"Internal Server Error"}` for JSON routes. Details are logged server-side.

## Key endpoints

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/api` | Instance information |
| `POST` | `/api/user` | Register a user |
| `POST` | `/api/auth/login` | Log in |
| `POST` | `/api/auth/logout` | Log out |
| `GET` | `/api/auth/me` | Current user |
| `GET` | `/api/explore` | List public repositories |
| `POST` | `/api/repo` | Create a repository |
| `POST` | `/api/repo/import` | Import a repository |
| `GET` | `/api/repos/{namespace}/{repository}` | Repository metadata |
| `POST` | `/api/repo/{namespace}/{repository}/fork` | Fork a repository |
| `GET` | `/api/repos/{namespace}/{repository}/branches` | List branches |
| `GET` | `/api/repos/{namespace}/{repository}/branch/{tree}/files` | List files for a branch/tree |
| `GET` | `/api/repos/{namespace}/{repository}/branch/{tree}/commits` | List commits for a branch/tree |
| `GET` | `/api/repos/{namespace}/{repository}/commits/{oid}` | Commit details |
| `GET` | `/api/sessions` | List active sessions |
| `DELETE` | `/api/sessions/{hash}` | Revoke a session |
| `GET` | `/api/ssh-keys` | List SSH keys |
| `PUT` | `/api/ssh-key` | Add an SSH key |
| `GET` | `/api/sso` | List enabled SSO providers |
| `POST` | `/api/orgs` | Create an organization |
| `GET` | `/api/orgs/{name}` | Organization metadata |
| `GET` | `/api/admin/stats` | Admin instance stats |
| `GET` | `/api/admin/health` | Admin component health |
| `GET` | `/healthz` | Basic HTTP health check |

Browse the full list of endpoints in the interactive explorer at `/rapidoc`.
